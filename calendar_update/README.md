# بروزرسانی تعطیلات رسمی تقویم

برنامه، تعطیلات قمری (عید فطر، عاشورا و ...) را به‌صورت پیش‌فرض با محاسبه‌ی نجومی
نشان می‌دهد که ممکن است با اعلام رسمی یک روز اختلاف داشته باشد.

وقتی کاربر در اول یا پانزدهم اسفند روی اعلان «بروزرسانی تقویم» بزند، برنامه فایل
`holidays.json` همین پوشه را از گیت‌هاب دانلود می‌کند و برای هر سالی که در آن فایل
آمده باشد، به‌جای محاسبه‌ی نجومی از تاریخ‌های رسمی استفاده می‌کند.

## فرمت فایل (تاریخ‌ها شمسی هستند)

```json
{
  "_readme": "...",
  "1406": {
    "lunar": [
      { "month": 1, "day": 7, "title": "عنوان تعطیلی" },
      { "month": 2, "day": 15, "title": "عنوان تعطیلی دیگر" }
    ]
  }
}
```

- کلید سال را به‌صورت عدد انگلیسی بنویسید (مثل `"1406"`).
- فهرست `lunar` باید **همه‌ی** تعطیلات قمریِ آن سال را داشته باشد؛ برای آن سال، جای
  محاسبه‌ی نجومی را می‌گیرد. تعطیلات ثابتِ شمسی (نوروز، ۲۲ بهمن و ...) داخل برنامه هست
  و نیازی به نوشتن ندارد.
- سالی که این فهرست را نداشته باشد، مثل قبل با محاسبه‌ی نجومی نمایش داده می‌شود.
- تغییر این پوشه باعث ساخت دوباره‌ی APK نمی‌شود.
